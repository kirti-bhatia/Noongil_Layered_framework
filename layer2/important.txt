### 4.X Perception Confidence Estimation Module

The Perception Confidence Estimation Module is responsible for calculating the reliability of the observations generated by the Perception Layer. Since Layer 2 processes multiple sensory modalities such as vision, audio, OCR, motion, and spatial input, each detected observation may have a different level of certainty. Therefore, a confidence estimation mechanism is required before forwarding the semantic perception output to the Context Graph Memory Layer.

The confidence score represents how reliable a detected perception element is. For example, an object detected by the vision module, a speech transcript generated by the audio module, a user activity recognized from motion signals, or a scene type classified from visual input may each receive an individual confidence value. These confidence values help later layers decide whether an observation should be stored, ignored, verified, or given higher priority.

The module calculates confidence at two levels. First, it preserves the local confidence scores produced by individual models, such as object detection confidence, OCR recognition confidence, speech recognition confidence, and activity recognition confidence. Second, it computes an overall perception confidence score by combining the confidence values of all available modalities using a weighted aggregation method.

The confidence calculation is represented as:

[
C_{overall} = \frac{\sum_{i=1}^{n} w_i \times C_i}{\sum_{i=1}^{n} w_i}
]

where (C_i) represents the confidence score of an individual modality and (w_i) represents the assigned weight of that modality. The weights are selected according to the importance and reliability of each modality in the given environment.

For the NOONGIL-X Perception Layer, the following modality weights are used:

| Modality                     | Weight |
| ---------------------------- | -----: |
| Vision / Object Detection    |   0.30 |
| Audio / Speech Understanding |   0.25 |
| OCR / Text Recognition       |   0.15 |
| Motion / User Activity       |   0.15 |
| Depth / Spatial Perception   |   0.15 |

The module also applies a confidence threshold. Observations with very low confidence are not directly discarded, but are marked as uncertain. This allows the higher layers to handle them carefully instead of treating them as confirmed facts.

The confidence categories are defined as follows:

| Confidence Range | Interpretation        |
| ---------------- | --------------------- |
| 0.80 – 1.00      | High confidence       |
| 0.60 – 0.79      | Medium confidence     |
| 0.40 – 0.59      | Low confidence        |
| Below 0.40       | Uncertain observation |

The output of this module is stored inside the final `layer2_output.json` file. It contains individual confidence values for detected scene type, objects, sounds, speech transcript, user activity, and spatial perception. It also includes the overall confidence score of the complete perception observation.

Example output:

```json
{
  "confidence_scores": {
    "scene_confidence": 0.91,
    "object_confidence": 0.93,
    "audio_confidence": 0.88,
    "activity_confidence": 0.92,
    "spatial_confidence": 0.86,
    "overall_confidence": 0.90,
    "confidence_level": "high"
  }
}
```

This module improves the reliability of the complete NOONGIL-X pipeline by ensuring that Layer 3 receives not only semantic observations, but also their estimated certainty. As a result, the Context Graph Memory Layer can create more accurate entities, events, and relations based on the trustworthiness of Layer 2 perception output.
